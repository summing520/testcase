技能工具

以下为 backend/integrations/ 目录中已集成的外部能力，供测试用例生成流程与运维脚本调用。 配置项见项目根目录 .env / .env.example。

飞书文档解析（Feishu）

backend/integrations/feishu/

将飞书在线文档或知识库 Wiki 页面拉取并转换为 Markdown， 作为工作台「步骤 1 · 需求确认」的需求输入来源。

需求解析 GET /feishu/url-preview POST /tasks/{id}/parse

目录结构

backend/integrations/feishu/
├── client.py      # 飞书 Open API：租户 token、文档元数据、正文拉取
├── parser.py      # URL 解析、块级内容 → Markdown
├── service.py     # 对外服务：预览标题、全文转 Markdown
├── cli.py         # 命令行：单链接导出 Markdown 文件
└── __init__.py

主要能力

  • feishu_resolve_url_preview：根据链接解析文档标题（不下载正文），供步骤 1 失焦预览。
  • feishu_url_to_markdown：拉取全文并转为 Markdown，写入任务 requirement_markdown。
  • 支持 /wiki/ 知识库与 /docs/ 文档；不支持 表格 /sheets/ 链接。
  • Wiki 节点为 docx 时走 docx 原始内容接口；其他类型走通用文件内容 + 块解析。

环境变量

变量说明
FEISHU_APP_ID飞书应用 App ID（必填）
FEISHU_APP_SECRET飞书应用 App Secret（必填）

命令行示例

python -m backend.integrations.feishu.cli "https://xxx.feishu.cn/wiki/xxxxx" -o output.md

数据库只读查询（Database）

backend/integrations/database/

连接外部业务库（MySQL / PostgreSQL 等，由 SQLAlchemy URL 指定），以只读方式列举表、查看表结构、采样数据， 并支持刷新 docs/knowledge/数据库表结构.md 知识文档，供「数据库表」类测试用例生成使用。

只读 SELECT 表结构巡检 schema-doc

目录结构

backend/integrations/database/
├── config.py      # DB_QUERY_URL、DB_QUERY_SCHEMA 等配置读取
├── client.py      # SQLAlchemy Engine 创建与连接异常
├── service.py     # list_tables / describe_table / sample_table_rows
├── cli.py         # 命令行：tables / describe / preview / schema-doc
└── __init__.py

主要能力

  • list_tables：列出当前库（或 schema）下可见表名。
  • describe_table：返回列、主键、外键等结构信息。
  • sample_table_rows：只读 SELECT * … LIMIT/OFFSET 预览数据（表名校验，防注入）。
  • schema-doc（CLI）：调用 schema_knowledge 服务，按库表元数据重写表结构知识 Markdown。

环境变量

变量说明
DB_QUERY_URLSQLAlchemy 连接串，如 mysql+pymysql://…（必填方可连库）
DB_QUERY_SCHEMA可选，PostgreSQL 等指定 schema
DB_SCHEMA_DOC_*表结构文档生成相关（是否启用、忽略库、图规模上限等）

命令行示例

# 列出所有表
python -m backend.integrations.database.cli tables

# 查看表结构
python -m backend.integrations.database.cli describe my_table

# 预览表数据（默认最多 50 行）
python -m backend.integrations.database.cli preview my_table --limit 20

# 刷新 docs/knowledge/数据库表结构.md
python -m backend.integrations.database.cli schema-doc
