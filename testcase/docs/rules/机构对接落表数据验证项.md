# 翼支付 - 机构对接落表数据验证项

> 机构 code：yizhifu | 产品 code：yizhifu | 流程：全流程 API | 额度类型：循环额度

本文档汇总准入 / 授信 / 绑卡 / 提现 / 还款 / 通知各环节涉及的数据库表字段验证点。

---

## 准入

**表：`lps.ap_fund_check_request`**

| 场景 | 验证点 |
|------|--------|
| 准入成功 | 1. 新增一条记录<br>2. 字段 `state` 为 `1`<br>3. `biz_data` 包含 `outFlowNo`（外部准入流水号），且不为空 |
| 准入失败 | 1. 新增一条记录<br>2. 字段 `state` 不为 `1`<br>3. 字段 `msg` 不为空<br>4. `biz_data` 包含 `outFlowNo`（外部准入流水号），且不为空 |

## 授信

### 表：`lps.ap_fund_appl`

| 场景 | 验证点 |
|------|--------|
| 授信成功 | 1. 新增一条记录<br>2. `Apply_state` = `APS`<br>3. `extention` 落库外部授信号 |
| 授信拒绝 | 1. 新增一条记录<br>2. `Apply_state` = `APJ`<br>3. `extention` 落库外部授信号 |
| 授信结果查询-授信中 | `Apply_state` = `APR` |
| 授信结果查询-授信成功 | `Apply_state` = `APS` |
| 授信结果查询-授信拒绝 | `Apply_state` = `APJ` |

### 表：`ams.ac_pilot_account`

| 场景 | 验证点 |
|------|--------|
| 授信成功 | 1. 新增一条记录<br>2. 额度在有效期内<br>3. `avaiable_amt` > 0<br>4. `staus` 为 `NNR` |
| 授信拒绝 | 无新增记录 |
| 额度状态查询-正常 | 1. 新增一条记录<br>2. 额度在有效期内<br>3. `avaiable_amt` > 0<br>4. `staus` 为 `NNR` |
| 额度冻结 | 1. 用户记录更新<br>2. 额度在有效期内<br>3. `avaiable_amt` = 0<br>4. `staus` 为 `NNR`（说明：部分机构需改为冻结，部分机构还需恢复为 `NNR`） |
| 额度过期 | 1. 用户记录更新<br>2. 额度已过期<br>3. `avaiable_amt` = 0<br>4. `staus` 为 `NNR` |

## 提现

### 表：`lcs.pilot_putout_calc`

| 场景 | 验证点 |
|------|--------|
| 借款试算 | 每次试算落库一条记录 |

### 表：`lcs.pilot_tran_proc_db`（借款流水表）

| 场景 | 验证点 |
|------|--------|
| 借款申请 | 新增一条记录 |
| 放款中 | 更新状态为 `DB_DRAW_PROCESSING` |
| 放款成功 | 更新状态为 `DB_PUTOUT_SUCCESS` |
| 放款失败 | 更新状态为 `DB_PUTOUT_FAIL` |

### 表：`lcs.pilot_plan`

| 场景 | 验证点 |
|------|--------|
| 放款成功 | 新增还款计划一组记录 |
| 查询还款计划-初始化 | 1. 还款计划字段落库<br>2. `status` = `AP`<br>3. 应还字段之和 = `total_amt`（`prin_amt` + `int_amt` + `overdue_fee_amt` + `overdue_fee_oint_amt` + `overdue_fee_late_amt` + `other_fee_amt`） |
| 查询还款计划-第一期结清 | 1. 字段落库<br>2. 第一期 `status` = `FP`<br>3. 应还字段之和 = `total_amt`<br>4. 实还字段之和 = `act_total_amt`（含 `act_prin_amt`、`act_int_amt`、`act_overdue_fee_amt`、`act_overdue_fee_oint_amt`、`act_other_fee_amt`、`act_overdue_fee_late_amt`、`act_deduct_*` 等） |
| 查询还款计划-第二期逾期 | 1. 字段落库<br>2. 第二期 `status` = `OD`<br>3. 应还字段之和 = `total_amt`<br>4. 实还字段之和 = `act_total_amt` |
| 查询还款计划-全部结清 | 1. 字段落库<br>2. 整体 `status` = `FP`<br>3. 应还字段之和 = `total_amt`<br>4. 实还字段之和 = `act_total_amt`<br>5. 特殊费项（如有）：`fee1_amt`/`fee2_amt`/`fee3_amt`、`act_fee1_amt`/`act_fee2_amt`/`act_fee3_amt`、`act_deduct_fee1_amt`/`act_deduct_fee2_amt`/`act_deduct_fee3_amt`；应还费用 = 实还应还费用 + 本期实际减免费用 |
