# 渠道业务规则

> HUB 渠道对接测试用例生成须遵守的业务规则。与《业务术语》《渠道需求检查项》、步骤2 接口文档及同目录下渠道 Demo 用例规则一并使用。

---

## 一、适用范围

- 需求类型为 **渠道对接**：合作渠道（HUB）调用我方接口，我方分发至机构并回传渠道侧结果。
- 用例**章节结构**以所选渠道 Demo 规则为准；本文约束**测什么、不测什么、如何判预期**。

---

## 二、渠道流程模式 → 测试范围

| 渠道流程模式 | 授信（HUB 联调） | 用信/借还 | 说明 |
|--------------|------------------|-----------|------|
| **半流程（出额导下载）** | 撞库、进件、授信查询/通知、额度查询 | **不测** HUB 侧借还款接口 | 出额后导下载乐享借 APP，借还在 APP 内 |
| **全流程 API** | 授信 + 借款 + 还款 API | 全流程 API | 按 HOMO 或渠道自有接口文档全章节覆盖 |
| **全流程-借还 H5 / H5 全流程** | 授信 API | 借还 H5 | 区分 API 与 H5 段，H5 关注跳转与回跳 |

半流程判定关键词：半流程、出额导下载、预授信导下载。

---

## 三、检查项识别逻辑（生成须遵守）

与《渠道需求检查项》文末规则一致，生成用例时须体现：

1. **IRR36** 可对应 24+AMC / 24+权益 / 36利率；**IRR24** 可对应 24利率。
2. **借款模式候选**：IRR36 → 普通/权益/AMC；仅 IRR24 → 普通。
3. **AMC 账单合并 = 是/合并**：最终「渠道支持的借款模式」**不得包含 AMC模式**（即使机构侧为 24+AMC 定价）。
4. 检查项中的 **上线机构**、**内部渠道号**、**渠道名称** 等须原样写入用例，禁止替换为中文俗称。

---

## 四、授信环节（HUB 侧）

1. **撞库**：`canLoan` 1/0；超时按失败；权限/越权（错误渠道密钥）；MD5 长度边界。
2. **进件**：必填字段、活体有源/无源、设备 `osType`；在途拦截（授信中/出额/放款中/待还款等）。
3. **授信结果**：查询与回调 `AUDITING` / `PASS` / `REFUSE` / `FAIL` 一致。
4. **额度**：`ACTIVE` / `EXPIRED` / `REFUSE`；`limitUseErrStatus` 各枚举（`APPLYING_ERR`、`LENDING_ERR`、`OVERDUE_ERR` 等）。
5. **前置规则**：黑名单、hub 进件拦截（如 30 天）、APP 活跃（如 60 天）等按需求单独列场景。
6. **是否为预授信导下载**: 若为预授信导下载，则不存在授信拒绝和授信中，授信结果查询和推送都会返回授信成功。

---

## 五、用信环节（HUB 侧）

### 是否使用固定下载链接（生成用例时系统会自动判定并注入强制约束）

| 判定为「是」时的信号（满足其一即可） | 用例要求 |
|--------------------------------------|----------|
| 需求/对接文档出现「固定下载链接」「本地配置下载链接」 | 用信章节写 **固定着陆页** 下发与校验，**不写** HUB 提现/试算/绑卡/借款/还款 API |
| 出现着陆页 URL（含 `/land/uni/fenqi`，参数 `cvv`、`td_channelid`） | 校验链接形态、`td_channelid` 与检查项「外部获客渠道编号」一致、HTTPS 可访问 |
| Demo/需求写明授信通过后「本地配置下载链接」返回渠道 | 勿将 Demo 中 Nacos 动态配置表述当作本渠道主路径 |

| 判定为「否」时的信号 | 用例要求 |
|----------------------|----------|
| 对接「查询场景页面地址」等动态获取下载页接口 | 按接口文档/Nacos 动态配置编写，勿套用固定着陆页模板 |

**固定链接示例**（Python 后台着陆页）：`https://test2.xurongwl.com/land/uni/fenqi?cvv=73889&td_channelid=23467`

## 六、半流程 · 出额导下载专项

1. 授信 `PASS` 后验证渠道侧 **导下载入口** 与 **乐享借 APP 下载链接**（**固定着陆页** 或 Nacos/运营配置，以第五章判定为准）。
2. 额度 `ACTIVE` 且 `limitUseErrStatus` 为空方可引导下载；有不可用原因时不得误导为可提现。
3. **禁止**为半流程渠道编写 HUB 侧试算、绑卡、借款提交、还款计划等用例（Demo 骨架含借还章节时标「不涉及」或删章）。
4. Android / iOS / harmonyos 下载路径按产品说明验证。

---

## 七、全流程 API / 借还 H5

- 按 HOMO 标准接口或渠道提供文档（如小赢 V2 专属文档）展开借还款章节。
- 权益/AMC 借款模式与「渠道支持的借款模式」检查项一致；AMC 合并时无 AMC 借款模式用例。
- 会员/权益订单、行权链接等按接口文档有则写、无则跳过。

## 九、数据与落库

- 内部渠道号格式如 `HUB_XXXXX`；与 `hubChannelConfig` 配置一致。
- 半流程不涉及放款对账 SFTP/XXL 放款对账任务（除非需求明确要求）。
- 落库用例（若勾选数据库表）：使用 `HUB用户流程涉及表`，关注母单、渠道号、撞库/进件记录。

---

## 十、配置验证（渠道任务）

- Nacos：`md5Key` / `aesKey`、回调地址、mock 开关。
- Widek：AMC 账单合并与「上线机构的AMC账单是否合并」检查项一致。
- 无 AMC 费项渠道无需 AMC 账单合并配置。
