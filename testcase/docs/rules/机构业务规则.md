# 机构业务规则

> 机构对接（OSI 标准机构 / 非标准机构）测试用例生成须遵守的业务规则。与《业务术语》《机构需求检查项》、步骤2 接口文档及同目录下机构 Demo 用例规则一并使用。

---

## 一、适用范围

- 需求类型为 **机构对接**：我方调用机构接口完成授信/借款/还款，机构回调通知结果。
- 用例**章节结构**以所选机构 Demo 规则为准；本文约束**测什么、不测什么、如何判预期**。

---

## 二、机构类型与接口文档

| 类型 | 说明 | 用例范围 |
|------|------|----------|
| **OSI 标准机构** | 对接《OSI标准机构对接-接口文档》或《半流程导下载-接口文档》 | 按「流程概要」覆盖标准接口章节 |
| **非标准机构** | 按机构自有接口文档 | 仅覆盖需求与上传文档中的接口，勿套用 OSI 全量章节 |

---

## 三、流程概要 → 测试范围

| 流程概要 | 授信 | 用信/提现 | 借还 | 说明 |
|----------|------|-----------|------|------|
| **全流程 API** | API | API | API | 授信、借款、还款均在 API 联调范围内 |
| **授信 API + 提现/还款 H5** | API | H5 | H5 | 用例须区分 API 段与 H5 段；H5 关注跳转、回跳、合同展示 |
| **半流程 · 出额导下载机构 APP** | API | 导下载 | 机构 APP 内 | **不写 HUB 渠道借还款接口用例**；须含导下载/机构 APP 下载类场景 |

半流程判定关键词：半流程、出额导下载、导下载机构 APP。

---

## 四、授信环节通用规则

1. **准入撞库**：覆盖通过/拒绝；拒绝须对应 `reasonDesc` 或等价字段有说明。
2. **授信申请**：必填字段、嵌套对象（OCR、活体、联系人等）须与《授信字段表》及检查项中的机构编码一致。
3. **授信结果**：授信中 / 通过 / 拒绝；查询与回调状态一致，注意幂等与重复通知。
4. **额度**：额度有效/失效；循环额度与单笔单批在额度查询、提现约束上表现不同。
5. **在途订单**：母单处于授信进件中、审核中、出额、放款中、待还款时，新申请应拦截（与《业务术语》一致）。

---

## 五、借还款环节（仅全流程 / 借还 H5）

- 试算、绑卡、借款提交、放款结果查询/推送、还款计划、还款试算、还款结果等，按接口文档章节展开。
- 机构差异（补件、二次绑卡、增验活体/短信）须单独列场景。
- **定价模式**影响费项：IRR24 / IRR36 / 24+权益 / 24+AMC，用例中费率、费项展示与检查项「定价模式」一致。

---

## 六、半流程导下载专项

1. 授信通过后须验证 **导下载/提现入口** 与 **机构 APP 下载 URL**（或 H5 落地页）。
2. Android / iOS 下载路径分别验证；鸿蒙未上架须按产品说明写不支持或降级。
3. 借还在机构 APP 内完成，**不写入**渠道侧借还款接口用例。

---

## 七、数据与术语

- `fundCode` / 机构编码 / 机构产品代码：用例与检查项确认值**逐字一致**，禁止翻译成中文别名。
- 上线范围「APP、HUB」表示投放端，**不等同于 HUB 渠道对接**。
- 落库用例（若勾选数据库表）：关注母单/子单状态、授信单号、额度字段与接口一致性。

---

## 八、配置验证（机构任务）

- Nacos：机构密钥、回调地址、mock 开关等按机构编码配置。
- 非 OSI 机构不上线标准 OSI 默认文档时，以实际上传接口文档为准。
