# 渠道需求检查项

对接前从需求文档中识别并确认以下信息，便于测试用例生成与验收。

### check 项与 check 内容


| check项           | check内容                                                                            |
| ---------------- | ---------------------------------------------------------------------------------- |
| 渠道名称             | 如：美易借钱                                                                             |
| 内部渠道号            | 如：HUB_MEIYIJIEQIAN                                                                 |
| 渠道合作方            | 如：国美                                                                               |
| 外部获客渠道编号         | 如：23462                                                                            |
| 是否预授信             | □ 是 □ 否                                                                          |
| 渠道流程模式           | □ 半流程(出额导下载) □ 全流程API □ 全流程-借还H5 □ H5全流程                                           |
| 授信申请方式(进件模式)           | □ 批量提交(批量进件) □ 单个提交(轮询进件)                                                          |
| 额度类型             | □ 单笔单批 □ 循环额度                                                                      |
| 渠道支持的借款模式        | □ 普通模式 □ 权益模式 □ AMC模式                                                              |
| 上线机构        | 如：juduoduo,jirongv2,……                                                             |
| 上线机构的定价模式    | □ 24+AMC □ 24+权益 □ 24利率 □ 36利率                                                     |
| 上线机构的AMC账单是否合并 | □ 合并 □ 不合并                                                                            |
| 接口文档提供方          | □ 我方提供 □ 渠道提供                                                                      |
| 接口文档链接           | 如：[https://consumeapidoc.58.com/v3/1.html](https://consumeapidoc.58.com/v3/1.html) |
| 接口文档访问密码         | 如：888888                                                                           |



识别逻辑（请按顺序应用；后文约束可缩减前文候选，不得忽略）：
1. 渠道利率类型包含IRR36时，上线机构的定价模式可支持 24+AMC / 24+权益 / 36利率 ；利率类型包含IRR24时，上线机构的定价模式可支持 24利率。
2. 根据利率类型得到「渠道支持的借款模式」的**候选集合**（尚未考虑 AMC 账单合并）：
   - 支持 IRR36：候选为 **普通模式、权益模式、AMC模式**（三者为候选，非最终定案）。
   - 仅支持 IRR24：候选为 **普通模式**。
3. **AMC 账单合并约束（强制）**：对照检查项「上线机构的AMC账单是否合并」。若需求中明确为 **合并** 或 **是** 等表示「账单合并已开启」，则必须从上述候选中 **删除 AMC模式**；最终填写的「渠道支持的借款模式」**不得**再包含 AMC模式（即使候选来自第 2 条的 IRR36 情形）。
4. 补充说明：当账单合并为「是」时，机构侧可能仍为 24+AMC 定价但对外以 IRR36 返回渠道——这与第 3 条「渠道端不支持 AMC 借款模式」不矛盾，请勿据此把 AMC模式 写回借款模式。
