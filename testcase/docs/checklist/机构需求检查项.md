# 机构需求检查项

对接前从产品概况、机构配置或需求文档中识别并确认以下信息，便于测试用例生成与验收。

### check 项与 check 内容


| check项           | check内容                                                                            |
| ---------------- | ---------------------------------------------------------------------------------- |
| 机构ID             | 如：1047                                                                             |
| 机构编码            | 如：juronghua                                                                        |
| 机构名称            | 如：聚融花                                                                            |
| 机构产品代码          | 如：juronghua                                                                        |
| 机构产品名称          | 如：聚融花                                                                            |
| 是否标准机构               | □ OSI标准机构 □ 非标准机构（按照机构提供的接口文档对接）                                                          |
| 流程概要            | 如：1️⃣全流程API ；2️⃣ 全流程-授信API + 提现/还款H5； 3️⃣2️半流程-出额导下载机构APP                                                              |
| 定价模式            | 如：IIR24%，IIR36% ，IIR24%+权益；IIR24%+AMC                                                                          |
| 额度类型            | □ 单笔单批 □ 循环额度                                                                   |
| 结算方式            | 如：CPA                                                                              |
| 上线范围            | 如：APP、HUB                                                                         |



填写说明（请与需求、接口文档及产品配置交叉核对）：
1. 「机构编码 / 机构产品代码」以机构侧或对接文档中的 **机构标识、产品编码** 为准，二者可能相同也可能不同。
2. 「流程概要」需能概括：**授信**形态（如 API / H5）、**提现与还款**形态（如 API / H5）、是否含**半流程（出额导下载机构 App）**等关键事实。
3. 「定价模式」「额度类型」「结算方式」「上线范围」与商务/产品口径、费率披露及实际上线渠道保持一致；若需求仅有口述表述，请在 check 内容中摘录可核验原文或章节。
