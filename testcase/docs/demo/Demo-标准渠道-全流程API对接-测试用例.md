## 五、配置验证

### 5.1 Nacos 配置验证

- **渠道密钥配置**：检查 hubChannelConfig.json 配置
- **渠道回调地址配置**：检查 application.properties 配置
- **渠道回调接口 mock 开关配置**：检查 hubChannelConfig.json 配置
- **SFTP 服务器配置**：检查 sftp-server.properties 配置

### 5.2 Widek 配置验证

- **AMC 账单合并配置**：检查「搭售产品账单规则」配置

### 5.3 XXL-Job 配置验证（若渠道对接）

- **放款对账文件上传任务**：检查 XXL-Job 放款对账文件上传任务配置
