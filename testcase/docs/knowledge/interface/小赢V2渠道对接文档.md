# 中收api外导-循环通用-半流程

## 接入步骤

## 说明

合作方使用http post方式提交数据；输入、输出统一采用json格式

金额相关字段，单位为分。按照JSON规范，string类型的值放在双引号中，int类型不加双引号。

双方的请求消息都需要加密，加密方法相同，详见加解密说明部分

## 接入步骤

合作方接入需要做下列几步：

  1. ⼩赢给出产品id，md5Key，然后交换数据加密的公钥。

  2. 与⼩赢⼀起完成开发调试⼯作。

  3. 开发完后进⾏测试。

  4. 测试通过后发布上线，开放少量用户试单，然后根据转化数据作出调整；没有问题后全部放开流量。

## 加解密说明

双方数据使用对称加密+非对称加密的方式进行加密，流程：

  1. 双方生成RSA的公私钥，然后约定合作方标识、约定签名密钥和交换RSA公钥
  2. 请求方生成随机的AES密钥，对明文进行加密，然后使用对方的RSA的公钥对这个随机密钥进行加密  
说明：AES加密为ECB模式，密钥为128位
  3. 最后将AES加密后的数据、RSA加密后的随机密钥、当前时间戳拼在一起，用MD5算法生成签名  
说明：签名字符串的格式为：合作方标识+密文+加密后的密钥+时间戳+签名密钥
  4. 接受方校验签名后，RSA解密得到随机密钥，然后再做AES解密得到明文



具体细节参见demo
