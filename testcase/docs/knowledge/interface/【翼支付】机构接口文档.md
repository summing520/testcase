# 1.  引言

## 1.1.      编写目的

本说明书是中国电信翼支付消费金融业务前置接口规范。

## 1.2.      适用范围

本说明书提供给系统设计人员、软件开发人员、客户方的系统设计人员和项目评审人员。

# 2. 接入说明

## 2.1     符号定义

| 序号 | 符号缩写 | 符号性质 | 符号说明 |
| --- | --- | --- | --- |
| 1 | M | 强制域(Mandatory) | 此域必选，否则将被认为格式出错 |
| 2 | C | 条件域(Conditional) | 此域在一定条件下必选 |
| 3 | C1 | 条件域(Conditional) | 此域在有值情况下必选 |
| 4 | O | 选用域(Optional) | 此域由发送方自选 |

## 2.2    交互模式

本文档说明了合作方接入翼支付资产平台所需要遵循的接口规范以及加密、解密、签名等相关事宜，接入方接入翼支付需要遵循此规范实现相应的接口。对于每一个具体业务，会定义每一个业务的参数列表，返回值及错误列表，请在个具体业务接口参考具体的参数、返回值及错误列表。

1)  接口协议：HTTPS

2)  接口必须提供对POST方法的支持

3)  所有的字符编码需要UTF-8

业务参数是指所访问接口自身需要的参数，如无特别说明，所有接口文档，所示参数均位于param域，文档不再另行标注。

| 字段 | 含义 | 类型 | 必填 | 备注 |
| --- | --- | --- | --- | --- |
| assetCode | 资产编码 | String | M | 资产编码，翼支付分配 |
| assetProductCode | 资产产品码 | String | M | 资产产品码，翼支付分配 |
| platform | 平台 | String | M | h5 |
| channel | 渠道 | String | M | 渠道编码，翼支付分配 |
| bizNo | 合作方请求流水 | String | M | 每次请求的唯一标识bizNo |
| apiCode | 调用接口名 | String | M | 见各接口method对应枚举值 |
| param | 业务参数 | String | M | 业务参数json格式字符串 |

eg:

```json
{

"bizNo": "2025122316241269486747",

"assetCode": "翼支付分配",

"apiCode": "md5AuthAccess",

"param": "{\"mobileNo\":\"9B523F48A10B4\",\"idNo\":\"48FCFA\",\"userId\":\"fc64\"}",

"channel": "翼支付分配",

"assetProductCode": "翼支付分配",

"platform": "h5"

}
```

返回数据data是翼支付返回给接入方的业务参数，如无特殊说明，接口文档中所述返回参数均位于data域，文档不再另行标注。

| 字段 | 含义 | 类型 | 必填 | 备注 |
| --- | --- | --- | --- | --- |
| success | 成功标识 | String | M | true成功  false失败 |
| code | 错误码 | String | M |  |
| msg | 描述 | String | M |  |
| data | 返回数据 | String | C | json格式字符串 |

eg:解密后

```json
{

"msg": "成功",

"code": "000000",

"data": "{\"access\":true,\"failReason\":\"\",\"outFlowNo\":\"N2025122316210455800306036\"}",

"success": true

}
```

### 3.2.1.  接口描述

| 接口名称 | 查询协议列表 |
| --- | --- |
| method | agreementList |

LOAN 借钱--借款试算协议需传
REGISTER 授信阶段绑卡

| Agreement | Agreement | Agreement | Agreement | Agreement |
| requestSeq | 协议请求流水号 | String | M | 后续获取协议详情需要 |
| agreementName | 协议名称 | String | M | 协议名称 |
| url | 协议在线预览地址 | String | M | 可以访问的在线协议地址 |
